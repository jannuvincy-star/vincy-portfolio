# Jannu Vincy — Developer Portfolio

A responsive single-page portfolio inspired by the supplied reference website. It includes Home, About, Skills, Projects and Contact sections, a mobile navigation menu, and responsive layouts.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository for the portfolio.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In repository Settings → Pages, choose the `main` branch and `/ (root)` folder.
4. Save and wait for GitHub Pages to publish the site.
